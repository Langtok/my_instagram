# Welcome to My Instagram
***

## Task
What is the problem?
Instagram is one of the most popular social media platforms, allowing users to share photos, videos, and interact with others. This project aims to replicate Instagram’s core features while using modern cloud-native technologies.

Where is the challenge?
Recreating Instagram's UI while making it responsive.
Implementing authentication (login, signup, profile management).
Handling real-time social interactions (likes, comments, shares, notifications).
Media storage & retrieval using AWS Amplify and S3.
Managing relationships (followers, following, user interactions).

## Description
This project is a full-stack Instagram clone built using:

Frontend: ReactJS
Backend: AWS Amplify (GraphQL API, DynamoDB, S3, Cognito, Lambda)
Authentication: AWS Cognito
Database: AWS DynamoDB
Storage: AWS S3 for images & videos
Key Features Implemented
✅ User authentication (login, signup, forgot password)
✅ User profile (edit profile, bio, avatar)
✅ Post creation (text, images, videos, filters)
✅ Like, comment, and share posts
✅ Follow/unfollow users
✅ Real-time notifications
✅ Explore & search functionality
✅ Stories & Reels (upcoming)

## Installation
Prerequisites
Install Node.js (v16+ recommended)
Install AWS Amplify CLI
Install Git
Steps to Install
Clone the repository

$> git clone https://github.com/your-username/my-instagram-clone.git
$> cd my-instagram-clone

Install dependencies
$> npm install
$> Configure Amplify
$> amplify init
$> amplify add auth
$> amplify add api
$> amplify add storage
$> amplify push

Start the development server
$> npm start
The app should now be running on http://localhost:3000/

## Usage
How does it work?
Sign up / Login using email.
Edit your profile (update avatar, bio, and personal details).
Create a post (upload an image/video, add captions, apply filters).
Interact with posts (like, comment, share, save).
Follow users to see their posts in your feed.
Check notifications for likes, comments, and follows.
